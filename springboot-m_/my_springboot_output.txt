--- 16. TRANSACTION PROPAGATION & ISOLATION ---
Ex 16.1 - Propagation.NESTED -> Creates DB Savepoint within existing TX (partial rollback)
Ex 16.1 - Propagation.NEVER -> Throws exception if called inside an active TX
Ex 16.1 - Propagation.MANDATORY -> Throws IllegalTransactionStateException if no outer TX exists
Ex 16.1 - Propagation.REQUIRES_NEW -> Suspends outer TX, creates completely independent inner TX
Ex 16.1 - Propagation.REQUIRED (Default) -> Joins existing TX, or creates new one
  [AuditLog REQUIRES_NEW] Committed audit independently: ORDER_ATTEMPT_FAILED
Ex 16.2 - REQUIRES_NEW guarantees audit logging even when outer order creation rolls back
Ex 16.3 - Anomalies: Dirty Read (Reads uncommitted data) | Non-Repeatable Read (Row re-read changes) | Phantom Read (New rows appear)
Ex 16.4 - Isolation.READ_COMMITTED -> Prevents Dirty Read (Default in PostgreSQL, Oracle, SQL Server)
Ex 16.4 - Isolation.SERIALIZABLE -> Prevents Dirty Read + Non-Repeatable Read + Phantom Read (Full locking)
Ex 16.4 - Isolation.REPEATABLE_READ -> Prevents Dirty Read + Non-Repeatable Read (Default in MySQL)
Ex 16.5 - TransactionSynchronizationManager binds DB Connection to current thread via ThreadLocal
